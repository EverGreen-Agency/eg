## Instruções para Implementação no WordPress:

### 1. **Instalar ACF (Advanced Custom Fields)**
- Instale o plugin ACF no WordPress
- Crie um novo "Field Group" chamado "Case Study Data"

### 2. **Configurar Localização**
- Post Type = "autoridade"
- Taxonomy = "category" 
- Term = "cases"

### 3. **Criar os Campos**
Use exatamente os nomes dos campos conforme a documentação:
- `client_name` (Text)
- `industry` (Text)
- `category` (Select: B2B, B2C, E-commerce)
- `project_duration` (Text)
- `roi` (Text)
- `challenge` (Textarea)
- `solution` (Textarea)
- `implementation` (Textarea)
- `metrics` (Textarea)
- `results` (Textarea)
- `technologies` (Textarea)
- `testimonial` (Textarea)
- `timeline` (Textarea)

### 4. **Criar os Posts**
1. Crie um novo post do tipo "autoridade"
2. Adicione à categoria "cases"
3. Cole os dados dos campos ACF
4. Adicione título e imagem destacada
5. Publique

### 5. **Teste**
Acesse `/autoridade/slug-do-post` para ver o layout rico em ação!
